# Bonky Inu (vendored source)

Upstream: https://github.com/cryptoloutre/bonky-inu-devnet

The playable resurrection for Remember lives in `src/remember-frontend/bonky-inu/` (ported for modern Node + iframe embed).

This folder keeps the original Next.js 12 frontend for reference. It requires Node 16–18 to run standalone:

```bash
cd demo/bonky-inu-devnet
npm install
npm run dev
```
